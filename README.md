# TH COMPANY ERP

ERP SaaS da TH COMPANY para bares, distribuidoras de bebidas e restaurantes.

## Status atual

**Etapa 1 — Fundação do projeto.** Esta versão contém a estrutura inicial do frontend e um dashboard demonstrativo. Os indicadores exibidos são exemplos visuais, não dados reais nem funções operacionais.

## Tecnologias planejadas

- React + TypeScript + Vite
- CSS responsivo com identidade visual preto, dourado e cinza
- PostgreSQL e backend Node.js a serem adicionados em etapas futuras
- GitHub para versionamento e revisão

## Requisitos

- Node.js 20 ou superior
- npm

## Executar localmente

```bash
npm install
npm run dev
```

Para validar a compilação:

```bash
npm run build
```

## Estrutura

- `src/App.tsx` — shell e dashboard demonstrativo
- `src/styles.css` — identidade visual e layout responsivo
- `src/main.tsx` — ponto de entrada React
- `index.html` — documento HTML da aplicação

## Próximas etapas propostas

1. Aprovar e validar esta fundação visual.
2. Definir autenticação, empresas e perfis de acesso.
3. Projetar o banco de dados e a API com isolamento multiempresa.
4. Implementar produtos e estoque.
